# RabbitMQ Java Integration Examples

Practical implementations of message queuing patterns with RabbitMQ in Java.

## Patterns Covered
- **Direct Exchange**: Point-to-point worker queues.
- **Fanout Exchange**: Publish/subscribe broadcasting.
- **Topic Exchange**: Pattern-matched routing.
- **Dead Letter Exchanges (DLX)**: Handling unroutable and failed messages.

## Tech Stack
- Java 21 LTS
- RabbitMQ Client & Spring AMQP
- Maven Wrapper
